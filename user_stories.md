# User Stories

## Doctor

- As a doctor, I want to view my appointments so that I can manage my schedule.
- As a doctor, I want to view patient information so that I can provide appropriate care.
- ...

## Patient

- As a patient, I want to book an appointment with a doctor so that I can receive medical care.
- As a patient, I want to view my appointments so that I can manage my visits.
- ...

## Admin

- As an admin, I want to manage doctors so that the clinic system remains up to date.
- As an admin, I want to manage patients so that patient records are maintained.
- ...
